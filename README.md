# KittenBot User Extensions (`kblock.kittenbot.cc` 1.89.25)

> ⚠️ **重要提醒（在 `kblock.kittenbot.cc` 使用「URL 導入」時）**：
> 請**不要**直接複製上方檔案列表點進去的 `https://github.com/.../blob/main/...` 網頁網址（GitHub 的 `blob` 網頁沒有 CORS 標頭，瀏覽器會報 `request failure`）。
> 請直接複製下方表格中的 **`raw.githubusercontent.com`** 或 **`gmiiliao.github.io`** 連結貼入「URL 導入」即可一鍵成功！

---
